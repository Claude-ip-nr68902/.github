<p>试水这件事，最怕两种极端：一种是上来就付整年，用两周发现线路不合适，钱压在里面退不出来；另一种是天天换免费样品，试了三个月也没得出任何结论。合理的做法是把试水分成五层，一层一层往下走，每层都有明确的验收标准，过不了就停在那一层，不必往下投钱。这篇按这五层拆开讲，重点说清每层要解决什么、用什么指标验收、最容易在哪一步多花钱。</p>

<h2>一、第一层 需求：先算清到底要几条</h2>
<p>很多人跳过这一层直接问价，结果买多了一半闲置，或者买少了不够用又临时加价补。</p>
<h3>按同时在线数算，不按账号总数算</h3>
<p>把过去一周的操作记录翻出来，看每天同时在线的峰值是多少个号。三十个号里同时活跃的往往只有七八个，按七八条线配就够，剩下的用共享线做轻量用途。这一步算清楚，后面的预算能省三成以上。</p>
<h3>给增长留一点余量</h3>
<p>按峰值的 1.2 倍备线，不要按 3 倍。余量留太多，闲置线的月费会一直躺着；留太少，扩号时需要临时加价买线，价格通常比常规价高。</p>

<h2>二、第二层 出口：什么叫"干净"，要能量化</h2>
<p>干净不是感觉，是几个可以查的字段。这一层的验收标准写死，后面就不用反复纠结。</p>
<h3>三项硬指标</h3>
<p>一是归属类型，ipinfo 的 org 字段应是家宽运营商，出现 hosting、cloud、datacenter 就不算家宽；二是地址稳定性，七天里每 30 分钟探测一次，独享线只应出现一个 IP；三是风险标记，用 ipapi.is 或 scamalytics 查，被标为代理或数据中心的直接排除。三项全过，才算"干净"的候选。</p>
<h3>两项软指标：延迟与丢包</h3>
<p>延迟看 P95 而不是平均值，家宽线跨洲 200 到 350 毫秒属正常区间，但 P95 与平均值差距过大说明线路抖动明显。丢包连续一小时超过 1% 就要记录，连续三天都超就该换一条。这两项不决定能不能用，决定用得顺不顺。</p>

<h2>三、第三层 环境：试水期就把环境定下来</h2>
<img src="/tp.png" alt="家宽线路试水阶段出口探测与环境固定步骤">
<p>试水期最容易犯的错，是把环境当成临时配置：反正就试几天，随便开个浏览器就上。等到放量时发现环境要重建，之前试出来的数据全作废。</p>
<h3>试水就按正式标准配</h3>
<p>一个号一个独立的浏览器配置目录、一套独立指纹、一条对应出口。这四件在试水期就固定下来，后面放量只是复制，不是重搭。判断是否真的独立，同时打开两个号的检测页，把六层指纹逐项比，有两项以上相同就没做到。</p>
<h3>先把时区语言对齐再测</h3>
<p>出口在美国、时区还在东八区，测出来的验证频率会被这个矛盾放大，误判成线路不行。先对齐时区、语言、DNS 三项，再开始记录数据。这一步花十分钟，能避免后面把好线当成坏线淘汰。</p>

<h2>四、第四层 计费：短周期试，别一次付整年</h2>
<p>这一层直接关系到"试水不必一次付整年"这句话怎么落地。</p>
<h3>三种计费方式的适用期</h3>
<p>按量计费适合第一周，用多少付多少，常见每 GB 几元到十几元，仅供参考；周付或半月付适合第二到第四周，用来验证稳定性；月付适合确认可用之后。年付只在一个前提下考虑：这条线已经稳定跑了三个月以上，且服务商支持按月折算退款。看不到退款条款的年付，本质是把风险全留给买家。</p>
<h3>把试水预算单独列出来</h3>
<p>建议把试水预算控制在正式预算的两成以内。三条线加两周按量流量，通常几百元就能跑完整个验证流程。这笔钱的作用是买信息，不是买服务，花完就该有结论：哪条线留、哪条线退、放量到几条。</p>

<h2>五、第五层 放量：什么信号才值得批量续</h2>
<p>放量的判断标准要提前定，否则很容易被销售节奏带着走。</p>
<h3>三个信号同时满足</h3>
<p>一是试水的三到五条线连续 14 天没有出现断线超过十分钟的情况；二是验证弹窗次数在第二周比第一周下降或持平；三是订阅扣费环节一次通过，没有反复失败。三条同时满足，批量续才有依据；只有一条满足，说明还在验证期。</p>
<h3>放量按批次，不一次到位</h3>
<p>第一次扩到峰值的六成，观察一周；稳定后补齐到峰值。每批新线都要走一遍第二层的三项硬指标，不要因为"同一家服务商"就跳过检查。同一家不同批次的地址段质量可能差很多，这在行业里很常见。</p>

<h2>常见问答</h2>
<h3>试水要几条线才够判断？</h3>
<p>答：三条起步，五条更稳。三条可以看出服务商内部的地址质量是否一致，五条能覆盖不同地区或不同地址段。一条线试出来的结论参考价值有限，容易把偶发情况当成普遍规律。</p>
<h3>七天够不够判断一条线干不干净？</h3>
<p>答：基本够。七天覆盖了工作日与周末的作息差异，也够观察会话稳定性。要判断长期表现，可以延长到 14 天，但不必为了"更保险"拖到一个月，时间成本也是成本。</p>
<h3>按量计费会不会比包月贵很多？</h3>
<p>答：试水期不会，长期会。按量适合短期验证，跑满一个月的高频使用，按量总价通常高于包月。策略是按量试、包月用，两段分开算账。</p>
<h3>同一家服务商换批次，还要重新验吗？</h3>
<p>答：要。不同批次的地址段来源可能不同，上一批干净不代表这一批也干净。至少在第一批新线到货时做一次三项硬指标检查，通过后再批量续。</p>
